# MH Creators — Vercel deployment package

This is the Vercel-safe version of the site. Every local image is in this one folder, beside `index.html`, and uses a short lowercase filename with no spaces.

## Upload to GitHub

Upload the contents of this folder directly to the top level of a new GitHub repository. Do not place these files inside another folder in the repository.

## Deploy with Vercel

1. Import the GitHub repository in Vercel.
2. Set **Root Directory** to `./` (the repository root).
3. Use the default static-site settings; no build command is needed.
4. Deploy, then open the newly created deployment URL.

The public images are `banner.png`, `profile.png`, `payment-methods.png`, and `post-01.jpg` through `post-11.jpg`.
